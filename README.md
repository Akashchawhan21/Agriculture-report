# 🌾 Agriculture Report – Power BI

An interactive **Power BI dashboard** for analyzing agriculture-related data and identifying key trends and insights.

### 📊 Features

* Agriculture data analysis
* Interactive charts and visuals
* KPI cards and summary metrics
* Filters and slicers
* Trend and category analysis
* User-friendly dashboard design

### 🛠️ Tools Used

* Power BI
* Power Query
* DAX

### 📁 File

`Agriculture-report.pbix`

### 🎯 Purpose

This project demonstrates data cleaning, analysis, visualization, and dashboard development using Power BI.
